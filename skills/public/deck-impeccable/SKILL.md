# Deck Impeccable

Use this adapter on demand while planning or revising a presentation. Read only
the reference that matches the current need:

- `reference/layout.md`: hierarchy, grid, spacing rhythm, and density.
- `reference/critique.md`: structured critique language.
- `reference/polish.md`: final alignment, typography, and contrast pass.
- `reference/bolder.md`: increase commitment and compositional confidence.
- `reference/quieter.md`: reduce visual intensity without erasing intent.

Apply the underlying design principles to a fixed 1920x1080 slide canvas.
Do not apply responsive breakpoints, browser interaction, motion, mobile states,
PRODUCT.md setup, frontend component workflows, or automated web detectors.

This adapter does not authorize direct file generation. Fresh decks still use
`prepare_deck_build` exclusively.

The mirrored references are from Impeccable and retain their Apache-2.0 license
and NOTICE. This adapter is a Sophia-specific modification.
